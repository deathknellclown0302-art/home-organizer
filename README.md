# 自宅の整理整頓 (Home Organizer)

スマートフォン上で動作する、自宅の収納場所と所持品を管理・検索するための個人向けアプリの試作プロジェクトです。

## 現在の最新版

**Phase 1.5 Rev C**

- 部屋 → 収納 → 引き出し → さらに下位階層まで管理
- 物の登録、編集、検索
- タグによる分類
- 物・収納場所の写真
- 場所の追加、編集、削除
- 編集モードによる一括削除
- 同一階層内のドラッグ＆ドロップによる並び替え
- 階層の深さに応じて自動的に増える配置選択
- 追加フォームのタブ移動中の入力内容保持

## 構成

```text
src/index.html                    # 現在の最新版
archive/                          # 開発過程の各フェーズ
CHANGELOG.md                      # 主な変更履歴
```

## 動作確認

`src/index.html` をAndroidのChromeなど、JavaScriptが動作するブラウザで開いて使用します。

## 開発方針

まずは自宅で実際に使用し、運用上の課題を見つけながら必要な機能を追加する方針です。現時点では「自分の家のどこに何があるかを簡単に登録し、後から探せること」を最優先にしています。
